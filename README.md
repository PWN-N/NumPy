# NumPy Learning Notebooks

A beginner-friendly collection of Jupyter notebooks covering NumPy arrays, indexing, operations, and practice exercises.

## Notebooks

| Notebook | Topics |
| --- | --- |
| `Numpy/Arrays.ipynb` | Array creation, generation, random values, attributes, methods, and reshaping |
| `Numpy/Array_indexing.ipynb` | Vector and matrix indexing, slicing, and boolean indexing |
| `Numpy/Array_operations.ipynb` | Arithmetic, broadcasting, copies, matrix operations, stacking, and splitting |
| `Numpy/Exercises.ipynb` | NumPy practice problems, including Sudoku and tabular data exercises |

## Requirements

- Python 3
- Jupyter Notebook
- NumPy

Install the requirements:

```bash
python -m pip install jupyter numpy
```

## Run the notebooks

From the repository root, start Jupyter:

```bash
jupyter notebook
```

Open a notebook in the `Numpy/` directory and run its cells.
